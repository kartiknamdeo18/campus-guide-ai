# CampusGuide AI — Sample Knowledge Base Data

This directory contains verified sample data for testing and demonstrating the CampusGuide AI College FAQ Assistant.

## Files
1. `sample_faqs.csv` — Contains 22 verified fictional college FAQs across 10 categories in both English and Hindi.
2. `academic_regulations_handbook.txt` — Plain text document containing college policies on attendance, exams, grading, degree requirements, and grievance redressal.
3. `scholarship_guidelines_2026.csv` — Tabular document specifying eligibility criteria, financial assistance schemes, deadlines, and required documentation.

## Note on Demonstration Data
All names, numbers, rules, and contact channels are designed for demonstration and hackathon testing purposes and do not represent a real university without custom configuration. Administrators can replace, add, or upload actual college documents at any time via the Admin Dashboard.
